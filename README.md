# campus-lost-and-found-cell-app
CampusLoop is a web application that brings the everyday life of a college campus into one shared place. It started as a class project built on Base44, from a simple observation: campus life already happens online, just badly scattered across notice boards, chat groups, and screenshots. CampusLoop pulls those threads together so students can connect with the people around them, keep up with what is happening on campus, and find the information and conversations that matter without digging through different apps. Sign-in is deliberately simple, with Google single sign-on or a standard email and password, and account recovery built in, and the app is live at campus-link-loop.base44.app. As a project, it covers the full path of a modern web build, from an idea in class to a deployed product, and its plan is to keep growing the loop into a genuine campus community.
